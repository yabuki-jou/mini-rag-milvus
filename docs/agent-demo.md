# Agent 演示步骤

前置条件：PostgreSQL、Milvus、Embedding 与 API 健康，知识库中已有一份解析
完成的企业制度或项目管理文档。

1. 创建用户和知识库，上传并解析文档。
2. 创建绑定该知识库的 Agent 会话。
3. 询问文档中有明确依据的问题，展示回答、文档名、页码、摘录和分数。
4. 询问知识库中没有依据的问题，展示明确拒答而不是编造。
5. 连续发送两轮相关问题，再读取 `/messages` 展示 Checkpoint 恢复的历史。
6. 读取 `/tool-calls`，展示工具名、耗时、完成/失败状态和脱敏摘要。
7. 使用另一个用户读取该会话，展示 403 所有权保护。

演示时必须明确：业务库是 PostgreSQL，SQLite 只用于 LangGraph Checkpoint；
标书解析和合规审查还未实现，请假领域已经删除。
